# mlflow_example
Пример использования mlflow для трекинга экспериментов

Запуск пайплайна &mdash; `python3 runner.py`

## Дополнительные модули

В репозитории также есть отдельные учебные модули:

- `registry/` — учебный model registry на FastAPI + PostgreSQL + MinIO
- `inference/` — ДЗ по оптимизации inference pipeline для `rubert-mini-frida`

Для inference-модуля см. `inference/README.md`.
